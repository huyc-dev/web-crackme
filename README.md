# Web CrackMe

这是一个我用来练习前端安全和逆向工程的网页版 CrackMe 项目。

## 🎯 项目简介
这是一个纯前端的密码验证挑战（CrackMe）。
**你的目标**：找到隐藏在页面中的正确密码，或者绕过验证逻辑。

## 🚀 如何开始挑战
1. 把 `index.html` 下载下来，直接在浏览器里打开。
2. 尝试在输入框里输入密码，看看会有什么反应。
3. 如果卡住了，试试按 `F12` 打开浏览器的开发者工具，或者直接查看 `index.html` 的源码。
4. 也可以访问我的网站[http://huyc.gt.tc]。
